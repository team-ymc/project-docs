# Feature: FT-005 전체 번역

## 1. Overview

- Summary: 학습 페이지에서 논문 본문 전체를 원문 옆 또는 아래에 한국어 번역과 함께 볼 수 있다.
- Status: In Progress
- Tracking: YMC-383, YMC-387, YMC-389
- Depends on: FT-004 논문 학습 뷰어

## 2. Feature Boundary

### In Scope

- 전체 번역 표시 배치 순환(안 보기 → 아래 → 옆)과 배치 기억
- 원문과 번역을 함께 표시하는 렌더. 구조 단위를 유지하고 원문은 그대로 남는다
- 번역이 없는 논문에서의 컨트롤 비활성과 사유 안내
- 파싱 뒤 별도 단계에서 생성된 번역의 적재, 번역 상태와 본문 조회 응답 제공

### Out of Scope

- 번역 언어 선택(한국어 외) → 후속(post-MVP)
- 사용자 요청 시점의 번역 생성·재생성 → 후속(post-MVP)
- 번역이 없는 기존 논문의 재파싱·재적재 → 후속(post-MVP)
- 번역 생성 자체와 그 재시도 → 파싱 뒤 번역 생성 단계 책임. 실패한 논문은 "번역 실패"로 서빙한다
- 인라인(부분) 번역 → FT-006

## 4. Stories

### Story 1. 사용자는 논문 원문 옆이나 아래에서 한국어 번역을 함께 볼 수 있다 `MVP`

- type: USER
- Source Userflows: UF-004 Step 1-4
- Acceptance Criteria:
  - 툴바의 `번역` 버튼은 누를 때마다 안 보기 → 아래 → 옆 → 안 보기로 순환하고, 현재 배치를 라벨(`번역` / `번역 · 아래` / `번역 · 옆`)로 드러낸다.
  - `옆`은 원문과 번역을 두 열로, `아래`는 원문 바로 아래에 번역을 둔다. 두 배치 모두 원문을 번역으로 갈아끼우지 않는다.
  - 제목 계열·이미지·표·수식·참고문헌은 번역을 붙이지 않고 원문만 전폭으로 둔다.
  - 그림·표 캡션은 본문 문단과 같은 방식으로 번역을 붙인다.
  - 번역 텍스트는 선택할 수 없다. 선택 팝업과 인라인 액션은 원문에서만 열린다.
  - 채팅이 열려 있어도 `옆` 배치를 유지한다. `옆`으로 들어갈 때 채팅 기본 폭을 320px로 맞추고, 이후 폭은 사용자 조작을 따른다.
  - 번역이 없는 논문에서는 `번역` 버튼이 비활성이고, 한국어 논문·번역 준비 중·번역 실패를 툴팁으로 구분해 안내한다.
  - 선택한 배치는 브라우저에 저장돼 다음 방문에 복원된다. 번역이 없는 논문에서는 저장값과 무관하게 안 보기로 적용하고 저장값은 지우지 않는다.
  - 화면 기준은 `design/v2/Paper Study Page.dc.html`의 트윅 `translationMode`(off/below/side) · `translationStatus`(not_applicable/pending/ready/failed) · `chat`(open/collapsed)이다.
- Depends on: FT-004 Story 2

### Story 2. 시스템은 파싱 뒤 만들어 둔 한국어 번역을 학습 화면에 제공한다 `MVP`

- type: SYSTEM
- Source Userflows: UF-004 Step 2-3
- Acceptance Criteria:
  - 번역은 파싱이 끝난 뒤 별도 단계에서 문서 패키지의 사이드카 파일로 생성된다. 사용자가 전체 번역을 켤 때 새로 생성하지 않는다.
  - 파싱이 끝나면 본문과 채팅은 바로 사용할 수 있고, 번역은 생성 완료 결과를 받은 뒤 적재된다.
  - 시스템은 사이드카의 블록별 한국어 번역과 문서 언어를 적재하고, 본문 조회 응답에 원문과 함께 담아 내려준다.
  - 본문·상태 조회 응답은 번역 상태를 해당 없음·준비 중·준비됨·실패로 구분한다. 문서의 파싱 상태와는 별개 필드다.
  - 준비 중인 논문은 학습 화면이 상태를 폴링하고, 준비되면 본문을 다시 불러온다. 서재에는 번역 상태를 보이지 않는다.
  - 번역 생성 실패는 문서의 파싱 상태를 바꾸지 않는다. 실패 코드를 기록하고 번역 없는 상태로 서빙하며, 자동으로 다시 요청하지 않는다.
  - 사이드카가 없거나 형식이 어긋난 패키지도 경고만 남기고 번역 없는 상태로 서빙한다.
  - 이미 적재된 논문은 다시 파싱하지 않는다. 번역이 없는 기존 논문은 번역 없는 상태로 남는다.
- Depends on: FT-003 Story 4

## 5. Done Criteria

- 사용자는 원문을 그대로 둔 채 옆·아래 배치로 번역을 함께 읽고 안 보기로 돌아갈 수 있다.
- 번역이 없는 논문은 비활성 컨트롤과 안내로 구분된다.
