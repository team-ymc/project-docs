# Feature: FT-006 인라인 액션

## 1. Overview

- Summary: 사용자는 논문 뷰어에서 인라인 액션을 통해 번역 기능과 AI에게 질문하기 기능을 사용할 수 있다.
- Status: Draft
- Tracking: YMC-240, YMC-362
- Depends on: FT-004 논문 학습 뷰어

## 2. Feature Boundary

### In Scope

- 인라인 액션 창 열기: 본문 텍스트 선택 후 선택 영역 옆에 인라인 액션 창 표시 (WF-010)
- 번역하기: 선택한 텍스트의 인라인 번역 결과 표시 및 닫기 (WF-011)
- AI에게 질문하기: 선택한 텍스트를 맥락으로 AI 튜터 패널에서 질문 시작 (WF-TBD)

### Out of Scope

- AI 질문 작성·전송·응답 생성·대화 이어가기 → FT-007 AI 튜터 채팅
- 전체 본문 번역 → FT-005 전체 번역
- 인라인 노트 작성 → 후속(post-MVP)
- 번역 또는 AI 질문 진입 실패·재시도 → 후속(post-MVP)

## 3. Userflow References

| Userflow | Relation |
|---|---|
| UF-005 인라인 기능 중 번역 기능 활용하기 | 인라인 번역 flow |
| TBD (인라인 액션 중 AI 질문하기) | 선택 텍스트를 맥락으로 AI 질문을 시작하는 flow |

## 4. Stories

### Story 1. 사용자는 본문 텍스트를 선택해 인라인 액션을 열 수 있다 `MVP`

- type: USER
- Source Userflows: UF-005 Step 1-2
- Acceptance Criteria:
  - 사용자가 본문에서 텍스트 범위를 선택하면 선택 영역 옆에 인라인 액션 창(WF-010)이 표시된다.
  - 액션 창에는 번역과 AI 질문 진입 액션이 표시된다.
- Depends on: FT-004 Story 2

### Story 2. 사용자는 선택한 텍스트를 같은 자리에서 번역하고 본문 읽기로 돌아갈 수 있다 `MVP`

- type: USER
- Source Userflows: UF-005 Step 3-5
- Acceptance Criteria:
  - 사용자가 번역을 선택하면 선택 영역 옆에 인라인 번역 결과(WF-011)가 표시된다.
  - 사용자가 결과 창을 닫으면 원문 읽기 상태(WF-008)로 돌아간다.
- Depends on: Story 1

### Story 3. 시스템은 선택 텍스트와 문맥을 바탕으로 인라인 번역을 제공한다 `MVP`

- type: SYSTEM
- Source Userflows: UF-005 Step 3-4
- Acceptance Criteria:
  - 시스템은 선택 텍스트와 필요한 주변 문맥을 입력으로 번역 결과를 생성한다.
  - 생성된 번역 결과는 선택 영역 옆의 인라인 결과 창에 표시된다.
- Depends on: FT-003 Story 4

### Story 4. 사용자는 선택한 영역을 맥락으로 AI 질문을 시작할 수 있다 `MVP`

- type: USER
- Source Userflows: TBD
- Acceptance Criteria:
  - 사용자가 인라인 액션에서 AI 질문을 선택하면 AI 튜터 패널(WF-TBD)이 열리거나 활성화된다.
  - 선택한 영역은 AI 질문의 맥락으로 AI 튜터 패널에 첨부되고, 사용자는 질문을 작성할 수 있다.
  - 질문 작성·전송과 응답 처리는 FT-007의 책임이다.
- Depends on: Story 1, FT-007 Story 1

### Story 5. 사용자는 여러 선택 영역을 하나의 질문에 누적 첨부할 수 있다 `MVP`

- type: USER
- Source Userflows: 없음 (design/v2 Paper Study Page 기준)
- Acceptance Criteria:
  - 사용자는 AI 질문 액션을 반복해 선택 영역을 컴포저에 최대 5개까지 누적 첨부할 수 있다.
  - 서로 다른 종류(텍스트 선택·이미지·표·수식)를 한 질문에 섞어 첨부할 수 있다.
  - 이미 첨부된 것과 완전히 동일한 선택은 다시 첨부되지 않고 기존 첨부가 유지된다. 부분적으로 겹치는 선택은 허용한다.
  - 상한에 도달한 상태에서 추가 첨부를 시도하면 안내가 표시되고 첨부되지 않는다.
  - 사용자는 첨부된 선택을 개별 제거할 수 있다.
  - 첨부된 선택들은 질문 전송 시 함께 전달되고 컴포저에서 사라진다.
- Depends on: Story 4

### Story 6. 사용자는 이미지·표·수식을 블록 단위로 첨부할 수 있다 `MVP`

- type: USER
- Source Userflows: 없음 (design/v2 Paper Study Page 기준)
- Acceptance Criteria:
  - 이미지·표·수식 블록은 내부 텍스트가 부분 선택되지 않고 블록 전체가 하나의 선택 영역(atomic)으로 다뤄진다.
  - 구성요소별 질문하기 액션은 해당 블록을 선택 영역으로 첨부하며, 본문 텍스트 선택 후 AI 질문 진입과 동일한 효과를 갖는다.
- Depends on: Story 4

### Story 7. 시스템은 첨부 시점에 선택 영역 크기를 검증한다 `MVP`

- type: SYSTEM
- Source Userflows: 없음
- Acceptance Criteria:
  - 시스템은 첨부 시점에 각 선택 영역이 FE↔BE 계약의 크기 제한(선택당 최대 150 blocks, 렌더링 content 최대 30,000자)을 넘지 않는지 검증한다.
  - 제한을 초과한 선택은 첨부를 차단하고 사용자에게 안내한다.
  - 서버가 SELECTION_TOO_LARGE로 거절한 경우 선택 영역이 너무 크다는 일반 안내를 표시한다.
- Depends on: Story 5

## 5. Done Criteria

- 사용자는 본문 텍스트를 선택해 번역 또는 AI 질문 액션을 선택할 수 있다.
- 번역 결과를 인라인에서 확인하고 닫으면 원문 읽기로 돌아갈 수 있다.
- AI 질문을 선택하면 선택 영역이 AI 튜터의 질문 맥락으로 첨부된다.
- 사용자는 종류를 섞어 최대 5개의 선택 영역을 한 질문에 첨부할 수 있다.
