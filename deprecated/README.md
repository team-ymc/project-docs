# Deprecated

더 이상 유지하지 않는 문서와 도구를 보관한다. 참고용이며 새 문서를 등록하거나 내용을 수정하지 않는다.

| 항목 | 대체 | 비고 |
|---|---|---|
| [`wireframes/`](wireframes/README.md) | [Design v2](../design/v2/README.md) 아트보드 | 화면 구조와 상태는 아트보드가 SSOT다. `WF-XXX` ID는 더 이상 발급하지 않는다. |
| [`userflows/`](userflows/README.md) | [Features](../features/README.md) | 사용자 행동은 Feature Story로 기술한다. `UF-XXX` ID는 더 이상 발급하지 않는다. |
| [`codex-skills/`](codex-skills/) | 없음 | WF·UF 문서를 만들던 Codex 스킬. 탐색 경로 밖으로 옮겨 자동으로 불리지 않게 했다. |

기존 Feature 문서가 참조하는 `WF-XXX`, `UF-XXX` ID는 이 디렉토리의 문서를 가리키며 이동 시점 그대로 두었다. 보관 문서 안의 경로는 이동 전 기준이다.
