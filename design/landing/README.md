# 마케팅 랜딩

마케팅 유입자에게 Paper Teacher의 논문 읽기 흐름과 핵심 기능을 소개하는 반응형 랜딩 시안이다.

## 화면

- [Paper Landing Page - Marketing](Paper%20Landing%20Page%20-%20Marketing.html)
- 흐름: 문제 제기 → 업로드·내 서재 → 논문 뷰어 → 전체 번역 → 선행지식 → AI 튜터 → 지식 그래프 → 시작 CTA.
- 뷰어는 본문·이미지·수식·표 4개 화면, 지식 그래프는 전체 구조·섹션 클릭 후 본문 패널 2개 화면을 화살표·중앙 점 표시·모바일 스와이프로 넘긴다.
- `landing-assets/`의 이미지는 2026-09-29 `dev.papertutor.co.kr`에서 캡처한 화면이다. 정적 HTML은 레이아웃·콘텐츠 검토용이다.
- 서비스 구현에서는 공통 상단 바를 사용한다. 시작 CTA는 비로그인 시 기존 인증 흐름을 열고, 로그인 시 내 서재로 이동한다. 정적 시안의 직접 인증 링크는 서비스 동작을 나타내지 않는다.
