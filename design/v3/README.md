# Design v3

Paper Teacher v3의 화면 디자인 인덱스다. v2 화면과 디자인 시스템을 상속하고, 선행지식 기능으로 달라지는 학습 화면 상태를 추가한다.

## Screens

| 화면 | 파일 | 요약 |
|---|---|---|
| 학습 · 선행지식 설명 | [Paper Study Page - Prerequisite Knowledge](Paper%20Study%20Page%20-%20Prerequisite%20Knowledge.dc.html) | 본문의 선행 개념을 하이라이트하고 선택한 개념의 영문 정의와 한국어 설명을 팝오버로 표시한다. |

## Screen State — 선행지식

- 상단의 `선행지식` 토글은 준비된 하이라이트 배열이 하나 이상일 때 활성화한다. 배열이 비어 있으면 비활성화하고 `표시할 선행지식이 없습니다` 툴팁을 표시한다.
- 토글은 처음에 꺼져 있으며, 사용자가 켜면 선행 개념을 본문 위에 연한 navy 배경으로 하이라이트한다. 토글을 끄면 받은 배열은 유지한 채 표시와 열린 팝오버만 닫는다.
- 하이라이트를 누르면 선택 구간 아래에 말풍선 형태의 설명 팝오버가 열린다.
- 팝오버는 개념명, 영문 정의, 구분선, 한국어 설명으로 구성한다.
- 팝오버 안에 별도의 `선행지식` 태그를 표시하지 않는다.
- 팝오버 하단에 설명 생성 근거를 안내하는 문구를 표시하지 않는다.
- 팝오버와 하이라이트 바깥의 논문 뷰어 영역을 누르면 팝오버가 닫히고, 하이라이트를 다시 누르면 캐시된 설명을 즉시 열 수 있다.
- 설명을 처음 생성하는 동안에는 원문 제목 아래에 점 3개 로딩을 표시한다. 실패하면 같은 위치에 `설명을 불러오지 못했습니다.`를 표시하며 별도 재시도 버튼은 두지 않는다.
