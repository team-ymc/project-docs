# 플랜 소개

Free와 Pro의 월간 사용 범위를 안내하는 반응형 페이지 시안이다. 서비스의 `/plans` 화면에 대응한다.

## 화면

- [Paper Plans Page - Marketing](Paper%20Plans%20Page%20-%20Marketing.html)
- Free 카드에는 [FT-011 플랜·사용량 제한](../../features/FT-011-플랜-사용량-제한.md)의 베타 정책인 논문 등록 월 3편, AI 질의 월 30회를 표시한다.
- Pro 카드에는 구체적인 횟수 대신 더 많은 논문 등록과 AI 질문이 가능하다는 방향을 보여준다. 가격과 결제·신청 동선은 표시하지 않는다.
- 카드 바로 아래에 월간 초기화 기준과 플랜 Q&A를 둔다. Pro Q&A에는 설문조사·이벤트 등을 통한 이용 기회가 곧 제공될 예정이라고 안내한다.
- 비로그인 Free CTA는 기존 인증 흐름, 로그인 Free CTA는 내 서재로 연결한다. Pro CTA는 같은 페이지의 이용 안내로 이동한다. 정적 HTML의 Free CTA 링크는 레이아웃 검토용이다.
